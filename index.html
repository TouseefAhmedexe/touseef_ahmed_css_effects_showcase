Effects lab

Visual effects, one by one

Each tile shows one CSS effect and names the properties behind it. Only the mask tile uses an image.

  • Glass panel

    Blurs what is behind it

    Glassmorphism

    backdrop-filter blurs the colorful dots behind a see-through panel. A browser without support shows a more solid panel instead.

  • Aurora

    Gradient text and animated gradients

    background-clip: text shows a gradient through the letters. The bar moves a wide gradient with transform, which is cheaper than animating the background position.

  • Clip-path shapes

    clip-path cuts an element to a polygon, a circle or an ellipse. The square turns into a diamond when you hover the tile. A box shadow would be clipped away, so a drop-shadow filter on the parent draws the shadow.

  • Image masking

    mask-image with a gradient fades the left photo to nothing, and turns the right photo into a soft circle. No extra image files are needed.

  • Blend modes

    mix-blend-mode mixes the overlapping circles (two use screen, one uses multiply). background-blend-mode mixes the layers of the tile's own background, and isolation keeps the blending inside the tile.

  • Animated border

    Animated border

    A conic gradient behind the card turns with transform. The card covers the middle, so only a thin moving edge is visible.

  • 3D flip

    perspective, transform-style: preserve-3d and rotateY turn the card, and backface-visibility hides the side that faces away. Use the mouse, the keyboard or a tap.

    • none
    • hue
    • saturate
    • gray
    • contrast

    Filters

    The same gradient with five filters: none, hue-rotate, saturate, grayscale and contrast.

Parallax

Layers that move at different speeds

Scroll past this band. The far layer moves slowly, the middle layer a little faster and the near layer fastest. In a browser without scroll-driven animations the layers stay still.
